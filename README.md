# MCP Chatbot with LangChain & MultiServerMCPClient

Ye project ek AI Chatbot ka hai jo **LangChain**, **OpenAI**, aur **Model Context Protocol (MCP)** adapters ka use karke multiple MCP servers (jaise ki local Math server aur remote/external servers) ke sath securely communicate karta hai.

---

## 🛠️ Prerequisites & Tech Stack

- **Python 3.11+**
- **uv** (Fast Python package installer and runner)
- **OpenAI API Key**
